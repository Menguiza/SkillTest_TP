# Skill Test for Teleperformance By Daniel Hoyos

## Test Requirements

---

## 🎯 Main Objective

Develop an organic and intuitive navigation experience.

All development (except for 3D models) must be original. That means particles, animations, blueprints, and materials must be created by the candidate using their own knowledge and expertise.

> ❌ Any candidate using external assets in these categories, or showing insufficient understanding to develop them, will be **automatically disqualified**.

The project must be developed in **Unreal Engine 4.23**.

---

## 🧭 Context

The project can be built using a **first-person**, **third-person**, or **isometric** perspective.

In each case, consider the **advantages and limitations** of your chosen approach regarding screen layout and user experience.

---

## ✅ Final Deliverable

1. Create a **scene with three rooms**, each with **interactable doors**.  
   - Door activation logic is up to your own design.

2. Each door must have a **material with an outline effect** that activates when the player is nearby.

3. One room must have a **table with a coffee mug**:  
   - Implement an **inspection system** that allows the player to:
     - Pick up the mug in first-person.
     - Rotate and zoom the object.

4. One of the doors must use a **key system**:  
   - The door remains locked until the key is found.

5. The key must be **inside a chest**, which should:
   - Play a **sound** when opened.
   - Emit **confetti particles** upon opening.

6. Include a **3D object with a holographic shader** somewhere in the environment.

7. Add a **library with a single interactable book**:
   - When interacted with:
     - The **camera focuses** on the book’s mesh.
     - The **library’s material fades** in opacity to highlight the book.

8. _(Optional)_ Display **on-screen messages** to communicate game events to the player via UI.

9. _(Optional)_ Implement a **basic inventory system** that notifies the player when they collect items (key, book, mug).

---

## ⭐ Bonus Points

Priority will be given to candidates who demonstrate:
- Excellent usage of Unreal Engine.
- Well-optimized projects.
- Solid presentation and attention to detail.

> 🎨 There are no specific art direction requirements. Feel free to choose your preferred visual style.
